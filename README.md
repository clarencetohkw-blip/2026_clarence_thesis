This repository contains all code used for this study. Data for the study may be made available upon request from the Savolainen lab.

Dominance Rank contains all code used to quantify and calculate David's Scores (DS).

Microbiome contains two folders: Bioinformatic Processing and Microbiome Analyses:
Bioinformatic Processing contains the Jupiter notebooks used for sequence data processing and taxonomic classification;
Microbiome Analyses contains the R notebooks used to perform community-level and genera-level analyses.

Personality contains all files used in PCA, spider plot generation and statistical analyses with linear models.
